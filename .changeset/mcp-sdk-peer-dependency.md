'@clerk/mcp-tools': minor
---

**Breaking:** `@modelcontextprotocol/sdk` is now an optional peer dependency instead of a dependency, so an app on MCP SDK 2.x (`@modelcontextprotocol/server`, as `mcp-handler` 2.x uses) no longer installs SDK 1.x for this package, and an app on SDK 1.x shares its copy instead of getting a second one. When the app's 1.x SDK differed from the one this package installed, the app's `McpServer` failed to type-check against `streamableHttpHandler` in the Express and Hono adapters. `@clerk/mcp-tools/client` and `@clerk/mcp-tools/next/client` run the SDK 1.x client, so an app that uses them must now list `@modelcontextprotocol/sdk` 1.29 or later in its own dependencies. The server entry points, `@clerk/mcp-tools/express`, `@clerk/mcp-tools/hono`, `@clerk/mcp-tools/next`, `@clerk/mcp-tools/server`, `@clerk/mcp-tools/tools`, and the stores, never import the SDK, in their code or their types, so they install, bundle, and type-check without it.

**Breaking:** `streamableHttpHandler` in `@clerk/mcp-tools/express` and `@clerk/mcp-tools/hono` now takes the SDK transport class as its second argument instead of importing the SDK, so an app that uses only the auth middleware, for example with MCP SDK 2's `@modelcontextprotocol/hono` or `@modelcontextprotocol/node`, builds without SDK 1.x. A bundler resolves every import in the code it bundles, so an import of the SDK, even a lazy one, fails the build of an app that does not install it. Pass `StreamableHTTPServerTransport` from `@modelcontextprotocol/sdk/server/streamableHttp.js` in Express and `WebStandardStreamableHTTPServerTransport` from `@modelcontextprotocol/sdk/server/webStandardStreamableHttp.js` in Hono, as in `streamableHttpHandler(createServer, StreamableHTTPServerTransport)`; the types are inferred from the class. Without it, `streamableHttpHandler` throws at setup.

**Breaking:** `completeOAuthHandler` moved from `@clerk/mcp-tools/next` to the new `@clerk/mcp-tools/next/client`, because it runs the SDK 1.x client and would otherwise make `@clerk/mcp-tools/next` load the SDK. Replace `import { completeOAuthHandler } from '@clerk/mcp-tools/next'` with `import { completeOAuthHandler } from '@clerk/mcp-tools/next/client'`, and install `@modelcontextprotocol/sdk`.
